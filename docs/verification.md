## Покрытые сценарии

Клиентский поток проверяется входящими Telegram updates и исходящим outbox с заглушкой Telegram. Тесты не отправляют сообщения людям.

- Точное приветствие и постоянная клавиатура, сохранение выбранного маршрута после согласия.
- Фото и PNG для ручного моделирования, повторные updates, одно подтверждение после нескольких снимков, передача готового STL.
- Ответ из подключённой группы через команду, кнопку и reply. Reply связывается с заказом только по ID сообщения, возвращённому Telegram. Чужая группа, неизвестное сообщение и посторонний участник не получают доступ.
- Каталог цветов, необязательные поля, скрытие и удаление, пять цветов на странице, изоляция ввода двух операторов.
- Своя высота слоя, границы заполнения и предупреждение ниже 5%.
- Сбор ФИО, телефона и адреса СДЭК; ручной тариф; сохранение цены печати и скидки при добавлении доставки; невозможность подтвердить старое предложение.
- Подтверждение оплаты из группы только после отдельного действия и ввода уникального банковского идентификатора. Повторный платёж не дублирует учёт.
- Кнопки производства до статуса «Отправлен» и «Выполнен»; возврат и запись фактических расходов.
- FIRST50: два участника, FIRST30: ещё пять после двух оплат, один код на человека, скидка свыше 600 ₽ без ограничения, конкурентный последний резерв, отмена и истечение срока.
- Сохранение снимка цвета после удаления каталожной записи.
- Отдельная миграционная проверка: создать схему версии 1.0.0, записать заказ с заполнением 60%, профилем FINE, количеством 5 и промокодом, обновить до 1.1.0. Параметры сохраняются, слой становится 0,12 мм, значения заполнения 1 и 100 принимаются, 101 отклоняется БД. Временная схема удаляется.

## Интеграция слайсера

HTTP-адаптер тестируется через локальный HTTP-сервер: выбирается кандидат с запрошенными слоем, заполнением и двумя стенками, а не произвольно выбранная рекомендация backend. Проверяются нестандартные 0,16 мм / 1%, тираж на отдельных пластинах, 429 и неправильный принтер.

Backend `/Users/oilbanana/printlab-backend` обновлён совместимо: диапазон слоя 0,08–0,28 мм, заполнения 1–100%, ограничение альтернатив сверху и удаление дубликатов. Последние изменения рекомендаций назначения детали сохранены. `./mvnw verify` backend: 53 теста без ошибок.

Три opt-in теста `SlicerCliTest` требуют установленного Bambu Studio и заданных `SLICER_TEST_EXECUTABLE`, `SLICER_TEST_PROFILES`. Их отсутствие не считается проверкой реального слайсера. Production deployment отдельно запускает настоящий Bambu через внутренний proxy на синтетической STL-модели.

## Ограничения проверки

Время слайсера является прогнозом. Фактическую точность расхода и времени нужно проверять контрольной печатью. Платёжные тесты проверяют учёт, а не банковский перевод. СДЭК не вызывается автоматически: тариф и оформление выполняет оператор.
