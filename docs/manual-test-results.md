## UI-прогон

GitHub Actions завершил деплой успешно. Health = UP. Миграция production 1.2 выполнена. Бот является администратором Printlab Orders; ограничение приватности Telegram не мешает ему получать сообщения группы.

CUA выполняет ввод, поиск чатов, постоянные reply-кнопки и файловые диалоги. Координатные нажатия inline-кнопок возвращают AXError.noValue / AXError.failure. Переподключение, смена размера/полноэкранного режима и клавиатурная навигация не исправили ошибку. Веб-сессия Telegram не авторизована; новый вход не выполнялся. Поэтому нажатия inline проверяются закрытым временным callback-клиентом обработчиков production, а файлы и текст передаются через настоящий Telegram. Это не равно ручному нажатию каждой inline-кнопки.

## Дополнительные результаты 1.2 до изменения тарифа

- №9: нестандартный слой 0,16 мм, заполнение 15%, одна деталь. Реальный Bambu завершил работу с первой попытки: 17,651709 г, 78,940218 мин. В группе проверены данные клиента и ручной тариф. Подтверждён неоплаченный заказ; реальных и тестовых платежей в production не создавали.
- №10: STL на фото-шаге отклонён; PNG принят; фото в текстовом обращении отклонено; текст доставлен группе. Из группы доставлены текст и фото, неверный PNG на шаге готового STL отклонён, настоящий Benchy принят. Создание нового заказа потребовало подтверждения; прежний черновик скрыт с сохранением данных.
- №11: одна фотография PNG принята. После выхода в помощь лишняя фотография отклонена. Выбор второго изображения не считается завершённой отправкой; подтверждённого результата для него нет.
- QA_NIGHT: мастер промокода создан/изменён, будущая дата отклонена стандартной причиной, выключение/архив/восстановление проверены callback-клиентом. Код оставлен выключенным и удалённым.
- Ошибочные слой 0,07/0,29, заполнение 0/101, количество 0/101 и текст вместо числа отклонены; заполнение 1% требует предупреждения. Пользовательские файлы отправлялись через нативный Telegram; inline-переходы частично через временный callback-клиент.

## Проверка 1.3

На H2 и PostgreSQL пройдено 55 тестов, ещё три opt-in проверки локального Bambu CLI пропущены. Семь тестов деплоя и полный демонстрационный цикл прошли. Все синтетические оплаты изолированы от production.

Перед деплоем сервер подтвердил FIRST50 2 пользователя / одно применение, FIRST30 8 / одно применение, открытие после FIRST50. У обоих оплаченные счётчики равны нулю. Секретный конфиг остаётся root:root 0600; изменения тарифа подготовлены отдельным pending-файлом для штатного обработчика деплоя. Пользовательский заказ №12 не редактировался в QA.

Данные интерфейсного прогона 1.2 выше не доказывают новый поток 1.3. Итог деплоя и новые наблюдения дополняются после проверки сервера.
