# PrintLab 1.4.0: подготовка к запуску

31.10.2026.

- В карточке оператора первым показано следующее действие: запрос получения → тариф СДЭК → подтверждение цены → подтверждение оплаты → начало печати → готовность → отправка/выдача → выполнение. Подтверждение поступления денег и банковский идентификатор сохранены.
- У уведомления «Готов к самовывозу» и в открытом заказе есть «Согласовать время». Кнопка открывает текстовое обращение по нужному заказу; после выполнения старая кнопка не работает.
- Самовывоз: одно сообщение с тремя адресами и ровно шестью кнопками выбора/ссылок.
- Поверхности в каталоге: «Матовый» и «Глянцевый». Миграция исправляет существующие записи; новые записи и сохранённые названия отображаются в мужском роде.

Проверки: H2 и PostgreSQL, по 126 тестов, 123 выполнены, 3 необязательных CLI пропущены, ошибок 0. Есть полный сценарий приоритетных действий, согласование самовывоза, шесть кнопок в одном сообщении, миграция каталога и погашение FIRST50/FIRST30 по оплатам с лимитами 2/8.

Сброс тестовых заказов не включён в миграцию и не выполняется при обычном деплое. Перед очисткой создана защищённая резервная копия на сервере, проверенная восстановлением во временную БД. Номера заказов не переиспользуются, чтобы старые кнопки Telegram не ссылались на новые заказы.

Результаты production-деплоя, окончательной очистки и проверки промокодов будут добавлены после выполнения.
