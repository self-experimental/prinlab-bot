# Профили Bambu Lab A1 mini

Разрешённые встроенные профили из официального Bambu Studio 02.08.02.61: A1 mini, сопло 0,4 мм, стандартный и детальный процессы, Generic PLA. Наследование `inherits` и шаблоны `include` развёрнуты помощником `scripts/prepare-slicer-profiles.py`. Источник, исходные имена и контрольные суммы записаны в `manifest.json`.

Это одноцветная печать одним материалом на столе 180×180 мм с высотой до 180 мм. Калибровка расхода конкретной катушки пока не выполнялась; владелец подтвердил PLA и штатное сопло 0,4 мм; цвет пока не указан.

Приложение создаёт отдельную копию профиля для каждого задания и записывает в неё выбранные слой, заполнение и поддержки. Внутренние файлы здесь не изменяются при оформлении заказа.

Настройки происходят из [Bambu Studio](https://github.com/bambulab/BambuStudio/releases/tag/v02.08.02.61); лицензионные условия проекта доступны в его [LICENSE](https://github.com/bambulab/BambuStudio/blob/master/LICENSE).
